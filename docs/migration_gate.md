# Migration Gate

Use this gate before moving any legacy file into tracked package code.

## Keep

- Reusable Python modules with explicit inputs and outputs.
- Small configuration templates that do not contain private paths.
- Minimal docs that explain public usage, assumptions, and extension points.
- Small synthetic fixtures only when they are required by tests.

## Exclude

- Simulation trajectories and generated structures.
- COLVAR, HILLS, STATE, LAMMPS dump, and scheduler log files.
- CSV, PNG, PDF, NumPy arrays, and report outputs generated by analysis runs.
- Backup files, copied historical variants, and editor temporary files.
- Case-specific absolute paths, conda paths, module loads, account names, and queue settings.
- One-off plotting scripts unless the plotting logic has been converted into a reusable API.

## Required Conversion

Before a legacy workflow is moved into `src/molsimflow`, convert it so that:

- paths are CLI arguments, config values, or function parameters;
- project-specific defaults are examples, not library defaults;
- comments and CLI help are in English;
- the workflow fits an existing namespace or justifies a new one;
- the public code has a small test, smoke fixture, or documented dry-run path.

## Audit Command

From the repository root:

```bash
python scripts/audit_public_repo.py
```

The default audit skips `legacy_sources/` because it is ignored.  To inspect the
local migration snapshot too:

```bash
python scripts/audit_public_repo.py --include-ignored
```
